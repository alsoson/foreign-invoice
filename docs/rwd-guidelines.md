# 版面 RWD 規則

網站要同時支援手機、平板、電腦三種螢幕。新增或修改頁面時，請照這份規則做。

使用 Tailwind CSS 的斷點，**手機優先**：沒有加前綴的 class 是手機版，再用 `sm:`、`md:`、`lg:`、`xl:` 往大螢幕調整。

## 斷點

| 前綴 | 最小寬度 | 對應裝置 |
| --- | --- | --- |
| （無） | 0 | 手機 |
| `sm:` | 640px | 大手機、手機橫放 |
| `md:` | 768px | 平板 |
| `lg:` | 1024px | 筆電、桌機 |
| `xl:` | 1280px | 大螢幕 |

## 共用版面（`src/components/AppLayout.tsx`）

| 螢幕 | 導覽方式 |
| --- | --- |
| 手機（< `md`） | 上方標題列＋下方分頁按鈕（`fixed`，要留 `pb-24` 避免擋住內容） |
| 平板（`md`） | 左側窄側邊欄，只顯示圖示（`w-20`） |
| 電腦（`lg` 以上） | 左側完整側邊欄，顯示圖示、文字與使用者資訊（`w-60`） |

- 內容區最大寬度 `max-w-6xl`，置中；左右留白 `px-4 sm:px-6 md:px-8`。
- 新增導覽項目時，只要加到 `AppLayout.tsx` 的 `NAV_ITEMS`，手機下方列與側邊欄會同時出現。
- 手機版的下方分頁按鈕最多放 4～5 個，超過要改用「更多」選單。

## 頁面規則

| 項目 | 規則 | 範例 |
| --- | --- | --- |
| 頁面標題 | 手機 `text-xl`，平板以上 `md:text-2xl` | `className="text-xl font-bold md:text-2xl"` |
| 卡片列表 | 依寬度 1／2／3 欄，**不要**在電腦上維持單欄長列表 | `grid gap-3 sm:grid-cols-2 md:gap-4 xl:grid-cols-3` |
| 表單 | 手機欄位上下排列；平板兩欄；電腦可排成一列 | `grid gap-3 md:grid-cols-2 lg:grid-cols-5` |
| 主要按鈕 | 手機撐滿寬度方便點；平板以上改為自動寬度 | `w-full md:w-auto md:px-8` |
| 設定、閱讀類頁面 | 內容太寬不好閱讀，限制寬度 | `max-w-2xl` |
| 表格 | 手機改成卡片顯示，或外層加 `overflow-x-auto` 讓表格可左右滑 | — |
| 文字 | 長名稱加 `min-w-0 break-words` 或 `truncate`，避免撐破版面 | — |
| 互動 | 手機用 `active:` 回饋，電腦加 `hover:` 效果 | `hover:bg-teal-700 active:bg-teal-800` |

## 手機注意事項

- 可點擊的區域高度至少 44px（約 `py-2.5` 以上）。
- 輸入框字級至少 `text-base`（16px），否則 iPhone 會自動放大畫面。
- 貼齊螢幕邊緣的元素要加安全區域：`pt-[env(safe-area-inset-top)]`、`pb-[env(safe-area-inset-bottom)]`（瀏海、Home 鍵橫條）。
- 高度用 `min-h-dvh`，不要用 `h-screen`（手機瀏覽器網址列會讓 `100vh` 不準）。

## 完成前檢查

在瀏覽器開發者工具（F12 → 切換裝置工具列）至少看這三種寬度：

- [ ] 手機 390px：沒有左右捲動、下方導覽列沒擋住內容
- [ ] 平板 820px：側邊欄只有圖示、列表為 2 欄
- [ ] 電腦 1440px：側邊欄完整、列表為 3 欄、按鈕不會撐滿整排
